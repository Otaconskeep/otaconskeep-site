Otacon does not install or configure an LLM for you. To chat with an agent, install Ollama separately and pull the model tier Otacon recommended. Its default provider talks to Ollama automatically once it's running. Voice synthesis, speech-to-text, and image/video generation follow the same pattern: the routing exists, but each needs its own provider connected (see status below).

Architecture

Built on a resource arbiter, not a script

User→ Agent (identity · memory · voice)→ Capability Router→ LLM / TTS / STT Providers

A provider-neutral resource arbiter sits beneath capability routing: workloads request logical CPU/RAM/GPU/VRAM and receive leases that respect placement, priority, and health, rather than agents hardcoding device indexes. Idle model residency can be reclaimed gracefully while active work is protected. Per-voice synthesis settings are configured individually rather than one global profile applied to every voice. This is the same architecture that, at full scale in the private Keep, extends to media, home, and multi-node GPU orchestration. See The Keep.

Install

One command, no experience required

This is the exact command from install_otacon.sh, committed at the root of the repository. It's safe to run more than once: every step skips whatever's already done.

  1. Open a terminal on an Ubuntu or Debian Linux machine

    Ubuntu Desktop: press the Super key, type terminal, press Enter. Already SSH'd in? You're already there.

  2. Paste the install command

    curl -fsSL https://raw.githubusercontent.com/Otaconskeep/otacons-ai-ecosystem/main/install_otacon.sh | bash

  3. Press Enter and wait

    First run takes 10–30 minutes: installs Python, Rust, and Otacon itself; builds a native .deb package; runs the self-test suite. It asks for your password once, for sudo.

  4. Open Otacon

    It prints and tries to auto-open a local web address, and detects your LAN IP too:

    Localhttp://127.0.0.1:5757
    LANhttp://<your-lan-ip>:5757

  5. Connect an LLM to actually chat

    Install Ollama and pull the model tier Otacon recommended during install. Otacon's default provider looks for Ollama at 127.0.0.1:11434 automatically. No config file editing required for the default setup.

Requires sudo to install a handful of system packages (build tools, Python, WebKit libs). This is what triggers the one password prompt. The script explicitly refuses to run as the root user itself.
Also detects your GPU (if NVIDIA), recommends qwen2.5:7b at 8GB+ VRAM or qwen2.5:1.5b otherwise, and falls back to CPU cleanly if no GPU is present.
