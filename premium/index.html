Expansion manual for WSL or Linux, including the errors

Lite must already answer on port 5757. This does not grant the $1 seat. Antonio issues that seat in Member HQ. These steps install the Expansion layer inside the same Ubuntu that is already running Lite.

1 Lite is already up inside Ubuntu

Open Ubuntu from the Start menu, not PowerShell. Confirm http://127.0.0.1:5757 loads in the Windows browser. If it does not, use the Lite WSL manual first.

2 Save the Expansion installer, then run it

Same Ubuntu user that installed Lite. Do not prefix this with sudo.

curl -fsSL -o "$HOME/install_otacon_expansion.sh" https://raw.githubusercontent.com/Otaconskeep/otacons-ai-ecosystem/main/install_otacon_expansion.sh bash "$HOME/install_otacon_expansion.sh"

If GitHub does not resolve inside Ubuntu, turn the VPN off and run wsl --shutdown from PowerShell, then reopen Ubuntu and retry. Windows being online does not prove Ubuntu is online.

3 Restart and confirm the seat 
sudo systemctl restart otacon
systemctl status otacon --no-pager

Hard-refresh http://127.0.0.1:5757. Locked premium rooms mean the license seat is not on yet. That is separate from this installer. Check Member HQ.

If Expansion stops, match the message
Wrong window or wrong Linux
This terminal isn't running Ubuntu or Debian
  1. You pasted the command into PowerShell, Command Prompt, or Git Bash. Those are not the installer window.
  2. Open the Ubuntu app from the Start menu, or a terminal on the Ubuntu/Debian machine, and run it there.
Unsupported OS / not Ubuntu 22.04, 24.04, or Debian 12
  1. Check with cat /etc/os-release.
  2. Those three releases are the supported ones. Other distros, including other Ubuntu versions, stop on purpose.
  3. OTACON_ALLOW_UNSUPPORTED_OS=1 continues anyway. Core's web UI may still fail. Treat that as unsupported, not as a fix.
sudo: password is invisible, or sudo is missing
  1. The password is your Ubuntu/Linux password. Nothing appears while you type. Press Enter.
  2. Do not run the whole installer as sudo bash. Run it as your normal user. It asks for sudo only for system packages.
  3. If the message says sudo isn't available, install sudo as root, or run the privileged phase as root. Do not grant NOPASSWD to all commands.
user phase must not run as root
  1. You started the script with sudo or as root. File ownership would be wrong.
  2. Close it. Open a normal user shell and run bash on the script again.
Packages stuck
apt/dpkg is locked, or "Could not get lock"
  1. Another update is running (Ubuntu Software or unattended-upgrades). Wait for it to finish.
  2. On WSL, from Windows PowerShell run wsl --shutdown, reopen Ubuntu, and rerun the installer.
  3. On a Linux PC, reboot if the lock does not clear, then rerun.
dpkg was interrupted / apt-get -f install failed
  1. The installer tries sudo dpkg --configure -a and sudo apt-get -f install -y by itself.
  2. If it still stops, the log names the package. Fix that package, then rerun the same installer. It is safe to run again.
  3. Repair log: ~/.config/otacon/logs/
A step timed out
  1. Usually apt mirrors, GitHub, or a sudo prompt nobody answered.
  2. Fix the network, then rerun the same command. The log path is printed in the error.
Disk, memory, and GitHub
Preflight failed (RAM / disk / network)
  1. Under 4 GB RAM or under 8 GB free in your home filesystem stops the install. 8 GB RAM and 20 GB free is the comfortable size. The chat model is the large part.
  2. Free space, or rerun with OTACON_INSTALL_DEFAULT_MODEL=0 to skip the chat-model download. Voice trainer can be skipped with OTACON_INSTALL_VOICE_TRAINER=0.
  3. If Windows can open GitHub but Ubuntu cannot, they are not the same network. Turn the VPN off, run wsl --shutdown from PowerShell, reopen Ubuntu, and test getent hosts github.com.
  4. On Windows 11, if that name still does not resolve, create %UserProfile%\.wslconfig with [wsl2] and dnsTunneling=true, run wsl --shutdown, and try again.
git fetch failed / cannot reach github.com
  1. This is the Linux or WSL network, not proof that Lite is missing.
  2. Same recovery as the preflight network failure above. Then rerun.
The page does not open
127.0.0.1:5757 is blank or refused
  1. Wait until the installer finishes. A blank page during download is normal.
  2. From Ubuntu: systemctl status otacon --no-pager and sudo journalctl -u otacon -n 80 --no-pager.
  3. If systemctl says systemd is not running, add this to /etc/wsl.conf and then run wsl --shutdown from Windows:
[boot]
systemd=true
  1. Port 5757 already in use is usually a previous Otacon. The installer restarts otacon.service. Use the journal if it does not come back.
  2. Open http://127.0.0.1:5757 from the Windows browser too. Do not publish that port on your router.
nvidia-smi failed, or Codec says no GPU
  1. Core still installs. Spoken voice (Piper) can run on CPU.
  2. Genome Voice Trainer is optional and needs an NVIDIA GPU visible inside Linux.
  3. If Windows nvidia-smi works and Ubuntu's does not: update the NVIDIA driver on Windows, reopen Ubuntu. On the guided Windows path, Fix-Otacon-GPU.bat is the repair.
Expansion on top of Lite
Otacon Core is not installed
  1. Expansion will not create Lite for you. Finish Lite until http://127.0.0.1:5757 loads, then rerun Expansion.
Python virtual environment wasn't found
  1. Core's ~/otacon-ai-ecosystem/.venv is missing or was deleted.
  2. Rerun the Lite installer as your normal user, then rerun Expansion.
expansion/ was not found after syncing
  1. The Core checkout is older than Expansion.
  2. If you have not edited files in ~/otacon-ai-ecosystem, the installer's recovery is fetch and reset to origin/main. That discards uncommitted edits in that folder.
  3. If you did edit files there, copy them out first. The soft-update path keeps a backup branch and a stash, and the log names them.
Surfaces stay locked after a successful install
  1. The installer does not grant the $1 seat. War Room and the other premium rails stay locked until entitlement is on.
  2. Confirm the seat in Member HQ, restart with sudo systemctl restart otacon, then hard-refresh :5757.
  3. Optional pieces (Genome Voice Trainer, Video Studio) can stay off without a GPU or Docker. The roster can still be installed.
Low disk for video packs
  1. Video Studio pack downloads are optional. Free space and use Set Up Video Studio in the product later.
  2. A pack warning does not roll back the roster install.

Rerun the same script after the fix. Log: ~/.config/otacon/logs/. Discord if the log names a package you cannot repair.

License & sharing protocol

One seat. One member. Clear rules.

  1. Issuance: You pay on Buy Me a Coffee → Antonio records payment → issues access name + password + PIN + License ID → registers the seat here.
  2. Seat limit: Default is 1 seat (one primary machine/household). Extra seats are issued deliberately, not implied.
  3. Unlock signal: Each successful unlock can notify Antonio with License ID, IP, timezone, and browser fingerprint. Repeated unlocks from unrelated places look like sharing.
  4. If credentials are shared: Seat may be suspended or revoked. Credentials are rotated. The original payer is contacted on Discord when possible.
  5. If you lose access or suspect a leak: Message Antonio in Discord with your License ID. Do not post passwords in public channels.
  6. Fair use: Teaching a friend is fine; handing them your password is not. They can support and get their own seat.

Antonio checks seats and payment refs in the operator desk. Members only see their own card above.
