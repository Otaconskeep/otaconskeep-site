Install Sonarr

Show steps for: Change path

What you are learning

Sonarr monitors, downloads, renames, and organizes TV shows into /data/media/tv.

You should already have

  • Docker installed
  • /data created
  • qBittorrent working
  • Prowlarr installed

Step 1 — Open your terminal

Go to the ARR project folder.

Windows
cd ~/homelab/arr
Linux
cd ~/homelab/arr
In plain words: Terminal is the text window where you type computer instructions.
More detail: Keep using the same folder every lesson.

Step 2 — Create the Sonarr container

Add Sonarr with /data mounted. Start it.

Windows
docker compose up -d
Linux
docker compose up -d
  sonarr:
    image: lscr.io/linuxserver/sonarr:latest
    ports: ["8989:8989"]
    environment: [PUID=1000, PGID=1000]
    volumes:
      - ./sonarr/config:/config
      - /data:/data
In plain words: Sonarr needs to see torrents and media under one /data tree.
More detail: Mounting only /data/media is not enough for hardlinks from torrents.

Step 3 — Open Sonarr

Visit the UI and set the root folder.

Windows
http://YOUR-SERVER-IP:8989
Linux
http://YOUR-SERVER-IP:8989
In plain words: Root folder = the shelf where finished shows live.
More detail: Settings → Media Management → Root Folders → Add /data/media/tv

Step 4 — Connect download client + Prowlarr

Add qBit (category sonarr) and Prowlarr sync/app connection. Click Test until green.

In plain words: Green tests mean the robots can phone each other.
More detail: Use Prowlarr’s Apps screen to push indexers into Sonarr.
