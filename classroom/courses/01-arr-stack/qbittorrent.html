Step 1 — Add qBit to Compose (start without VPN if you need a baby step)

Beginners may run qBit on the bridge network first. Intermediate: put qBit on Gluetun and publish ports on Gluetun.

  gluetun:
    image: qmcgaw/gluetun
    # configure VPN_SERVICE_PROVIDER + private env file — see Gluetun wiki
    cap_add: [NET_ADMIN]
    ports:
      - "8080:8080"   # qBit UI published here
  qbittorrent:
    image: lscr.io/linuxserver/qbittorrent:latest
    network_mode: "service:gluetun"
    environment:
      - PUID=1000
      - PGID=1000
    volumes:
      - ./qbittorrent/config:/config
      - /data/torrents:/data/torrents
    # UI at http://SERVER-IP:8080 via Gluetun
In plain words: Only the download truck uses the secret tunnel. Librarians stay on the normal road.
More detail: Gluetun can update qBit’s listen port when the VPN forwards one.

Step 2 — Create categories

In qBit: categories radarr, sonarr, anime, lidarr → save paths under /data/torrents/movies|tv|anime|music.

In plain words: Labeled mail slots so each librarian finds the right pile.
More detail: Disable UPnP if you manually forward. Prefer a real forwarded port.
