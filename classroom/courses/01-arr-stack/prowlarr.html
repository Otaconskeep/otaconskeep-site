Step 1 — Create the Prowlarr container

Add service and start Compose.

Windows
cd ~/homelab/arr && docker compose up -d
Linux
cd ~/homelab/arr && docker compose up -d
  prowlarr:
    image: lscr.io/linuxserver/prowlarr:latest
    ports: ["9696:9696"]
    environment: [PUID=1000, PGID=1000]
    volumes: ["./prowlarr/config:/config"]
In plain words: One phone book for search sources.
More detail: Open http://SERVER-IP:9696

Step 2 — Add one indexer

Add a single indexer and note the API key for ARR apps.

In plain words: Start with one source so failures are easy to see.
More detail: You will sync apps in the Sonarr/Radarr lessons.
