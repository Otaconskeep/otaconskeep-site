Step 1 — Add Radarr service

Mirror Sonarr mounts; open :7878.

Windows
docker compose up -d
Linux
docker compose up -d
  radarr:
    image: lscr.io/linuxserver/radarr:latest
    ports: ["7878:7878"]
    environment: [PUID=1000, PGID=1000]
    volumes:
      - ./radarr/config:/config
      - /data:/data
In plain words: Same filing rules, movie shelves instead of TV shelves.
More detail: Do not invent Custom Formats yet — Recyclarr comes next.
