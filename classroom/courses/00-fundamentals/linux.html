0.4 Linux path — Ubuntu / Debian + Docker

Install Docker Engine from Docker’s official docs for your distro. Add your user to the docker group, log out/in, then verify.

Show steps for: Change path

Action

sudo apt update
# follow https://docs.docker.com/engine/install/ for your distro
sudo usermod -aG docker "$USER"
# log out and back in
mkdir -p ~/homelab && cd ~/homelab
docker version
docker compose version
In plain words: Linux is the native home for Docker. Your user needs permission to talk to Docker without typing sudo every time.
More detail: After usermod, a full logout/login (or reboot) is required before group membership applies.
