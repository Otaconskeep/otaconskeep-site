What you are learning

Prove Docker can pull an image and run a container. This is the merge point for Windows and Linux paths.

  • ~/homelab (or equivalent) exists

Step 1 — Run hello-world

From your homelab folder:

Windows
cd ~/homelab   # inside WSL
docker run --rm hello-world
Linux
cd ~/homelab
docker run --rm hello-world
In plain words: If hello-world prints a hello message, Docker can download blueprints and run them. That is the skill ARR needs.
More detail: If this fails: Docker service not running, permissions (Linux group), or Desktop WSL integration disabled.
