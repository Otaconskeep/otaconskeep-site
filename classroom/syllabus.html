Expectations

In plain words: Read this block, then try the next action. If you feel stuck, tap What this means.
  • Complete classes in module order unless the map marks a class as early-optional (Class 15 may run beside 1–3).
  • Every class requires: prior-knowledge check, instruction, worked example, guided + independent practice, Feynman teach-back, retrieval check, lab, break/fix, mastery gate, reflection.
  • “It seems to work” is not evidence. Log command output, test buttons, redacted screenshots, or workbook rows.
In plain words: Logs are the app’s diary. Read the newest lines when something breaks.

Policies

In plain words: Read this block, then try the next action. If you feel stuck, tap What this means.
  • Use only indexers/content you are legally authorized to use.
  • Do not expose ARR, download clients, or admin UIs to the public internet.
  • Never commit or paste real passwords, API keys, or tunnel tokens into public repos or screenshots.
  • Back up before profile migrations, HA upgrades, and remote-access changes.
In plain words: This path is about safe remote reach or private download traffic — not opening every admin page to the world.
