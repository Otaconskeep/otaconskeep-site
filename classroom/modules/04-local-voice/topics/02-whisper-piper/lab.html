Overview

Module: Module 4 — Local Voice Assistant
Activity type: Lab (Practice)
Objective: Given CPU/RAM constraints, the learner can deploy local Whisper (STT) and Piper (TTS) via Wyoming, benchmark them separately, and record latency/quality tradeoffs before integration.

Hands-on

Guided lab

In plain words: Do these steps in order, one time, without skipping. Each step should leave proof you can show later.
More detail: If a step fails, stop and use Break/fix instead of inventing a new path.
1

Deploy Whisper via current HA Wyoming docs (add-on, container, or supervised path you actually support).

Linux / macOS (Terminal)
docker compose ps | egrep -i 'whisper|wyoming' || true
ss -lntp | egrep '10300|10301' || true
curl -sv telnet://127.0.0.1:10300 2>&1 | head
Windows (CMD / PowerShell)
docker compose ps
# Confirm the Wyoming STT endpoint host/port from your docs, then:
Test-NetConnection -ComputerName 127.0.0.1 -Port 10300
In plain words: Loopback talks only to this computer. Ping 127.0.0.1 to check the local IP stack.
2

Confirm model/language loaded in logs.

Linux / macOS (Terminal)
docker compose logs --tail=100 whisper 2>/dev/null || docker compose logs --tail=100 | egrep -i 'whisper|model'
In plain words: Compose is the recipe file that starts and stops your app group together.
3

Connect Wyoming STT in Home Assistant (Settings → Devices → add Wyoming).

In plain words: Home Assistant watches sensors and runs if-this-then-that rules for your house.
4

Fixed phrase set (workbook)—run each 3 times, record transcript + cold/warm latency:

turn on test lamp
turn off test lamp
what time is it
set timer for five minutes
ignore this please
In plain words: Do this step fully, then check that it worked before the next one. Focus: Fixed phrase set.
5

Change only one variable (model size, mic distance, or noise) and repeat one phrase set.

In plain words: Do this step fully, then check that it worked before the next one. Focus: Change only one variable.
6

Deploy Piper per current docs; keep voice model + metadata together.

Linux / macOS (Terminal)
docker compose ps | egrep -i 'piper|wyoming' || true
ss -lntp | egrep '10200|10201' || true
In plain words: Compose is the recipe file that starts and stops your app group together.
7

Add Wyoming TTS in HA; select the Piper voice.

In plain words: Voice is a chain: hear → turn into text → decide → speak back. Test one link at a time.
8

Synthesize five fixed responses (UI media player / tts.speak service). Confirm no clipping.

In plain words: Voice is a chain: hear → turn into text → decide → speak back. Test one link at a time.
9

Measure synthesis latency vs playback latency separately.

In plain words: Do this step fully, then check that it worked before the next one. Focus: Measure synthesis latency vs playback latency.
10

Stress strings: numbers, abbreviations, entity names, one long sentence.

In plain words: Home Assistant watches sensors and runs if-this-then-that rules for your house.
11

Change one voice parameter only (if supported); compare intelligibility.

In plain words: Do this step fully, then check that it worked before the next one. Focus: Change one voice parameter only.
Break / fix

Break / fix

In plain words: Break one thing on purpose, watch the failure, then repair it.
More detail: Change only one variable at a time.

Break/fix

  1. Point HA at the wrong Wyoming port; confirm failure mode; restore.

  2. Remove Piper metadata mismatch deliberately; observe error; restore matching pair.

  3. Saturate CPU with a disposable load; rerun one STT phrase; compare latency.

In plain words: A port is the door number you use in the browser to open the app.
