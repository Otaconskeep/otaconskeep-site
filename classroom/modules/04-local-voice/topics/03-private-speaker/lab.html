Hands-on

Guided lab

In plain words: Do these steps in order, one time, without skipping. Each step should leave proof you can show later.
More detail: If a step fails, stop and use Break/fix instead of inventing a new path.

Complete gates in order. Do not skip to end-to-end.

1

Inventory satellite hardware, mic, speaker, network, power, OS/firmware versions (workbook table).

In plain words: Do this step fully, then check that it worked before the next one. Focus: Inventory.
2

Stable identity. Set hostname + reserved IP. Restrict firewall to required LAN flows only.

Linux / macOS (Terminal)
hostnamectl
ip -br addr
ping -c 2 HA-IP
ping -c 2 STT-HOST
Windows (CMD / PowerShell)
hostname
ipconfig
ping -n 2 HA-IP
In plain words: Ping asks “are you reachable?” with a small echo packet. First tool when something seems offline.
