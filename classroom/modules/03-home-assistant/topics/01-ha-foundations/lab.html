Hands-on

Guided lab

In plain words: Do these steps in order, one time, without skipping. Each step should leave proof you can show later.
More detail: If a step fails, stop and use Break/fix instead of inventing a new path.

Goal: a reachable Home Assistant instance, one stable entity, dashboard proof, restart proof, and a backup you can restore from.

Prefer HA OS in a VM (Class 1) or a documented Container install. Record which one you use.

1

Deploy or document the install.
If new VM: create from Class 1, attach HA OS image per current docs, boot, note the onboarding URL. If Container:

Linux / macOS (Terminal)
# Example pattern — follow current HA Container docs for exact compose:
mkdir -p ~/ha-config
docker compose ps
# After your compose exists:
curl -sI http://127.0.0.1:8123/ | head
Windows (CMD / PowerShell)
curl.exe -sI http://127.0.0.1:8123/
In plain words: Loopback talks only to this computer. Ping 127.0.0.1 to check the local IP stack.
2

Stabilize the LAN address. Reserve DHCP or set static IP. Record http://HA-IP:8123 in the workbook.

Linux / macOS (Terminal)
ping -c 2 HA-IP
curl -sI http://HA-IP:8123/ | head
Windows (CMD / PowerShell)
ping -n 2 HA-IP
curl.exe -sI http://HA-IP:8123/
In plain words: DHCP is how most home devices get an IP automatically from the router.
3

Complete onboarding with a strong unique password, correct location/time zone. Do not reuse your email password.

In plain words: Do this step fully, then check that it worked before the next one. Focus: Complete onboarding.
4

Add one safe local integration (demo/sun/input helper is fine) or a local device you own.

In plain words: Do this step fully, then check that it worked before the next one. Focus: Add one safe local integration.
5

Assign area + rename entity ID before automations depend on it (Settings → Devices & services / Entities). Write old→new ID in the workbook.

In plain words: Home Assistant watches sensors and runs if-this-then-that rules for your house.
6

Dashboard card showing state + control for that entity.

In plain words: Home Assistant watches sensors and runs if-this-then-that rules for your house.
7

Developer Tools proof.

Linux / macOS (Terminal)
# From a machine that can reach HA — Long-Lived Token in password manager only:
export HA=http://HA-IP:8123
export TOKEN='YOUR_LONG_LIVED_TOKEN'
curl -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  "$HA/api/states/ENTITY_ID" | head -c 400; echo
Windows (CMD / PowerShell)
$HA = "http://HA-IP:8123"
$TOKEN = "YOUR_LONG_LIVED_TOKEN"
curl.exe -s -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" "$HA/api/states/ENTITY_ID"

Also use UI Developer Tools → States / Services to inspect attributes and call one safe service (example: toggle an input_boolean).

In plain words: Do this step fully, then check that it worked before the next one. Focus: Developer Tools proof.
8

Restart HA and prove recovery. UI restart or host reboot. Confirm entity + dashboard return. Time the outage in the workbook.

In plain words: Home Assistant watches sensors and runs if-this-then-that rules for your house.
9

Create a backup (HA OS: Settings → System → Backups). Copy the backup file off-box.

Linux / macOS (Terminal)
mkdir -p ~/backups/ha
# Copy from the path your install uses, e.g. backup share or download via UI
ls -lh ~/backups/ha
sha256sum ~/backups/ha/*.tar 2>/dev/null | tee ~/backups/ha/SHA256SUMS
Windows (CMD / PowerShell)
New-Item -ItemType Directory -Force $HOME\backups\ha | Out-Null
Get-FileHash $HOME\backups\ha\* -Algorithm SHA256 | Format-Table
In plain words: Make a safety copy first so a mistake does not erase your work.
10

Write the restore procedure in the workbook. If production risk is high, restore into a disposable VM instead of overwriting the live box.

In plain words: Do this step fully, then check that it worked before the next one. Focus: Write the restore procedure.
Break / fix

Break / fix

In plain words: Break one thing on purpose, watch the failure, then repair it.
More detail: Change only one variable at a time.

Break/fix

  1. Rename an entity after a dashboard depends on it—observe break—rename back or update the card.

  2. Stop the HA VM/container briefly; confirm UI down; start; confirm recovery.

Linux / macOS (Terminal)
# Container example:
docker compose stop homeassistant
curl -sI --max-time 3 http://HA-IP:8123/ || echo EXPECTED_DOWN
docker compose start homeassistant
curl -sI http://HA-IP:8123/ | head
  1. Attempt action on unavailable vs off entities; record the difference.
In plain words: Compose is the recipe file that starts and stops your app group together.
