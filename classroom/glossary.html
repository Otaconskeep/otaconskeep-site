What the hell does that mean?

Permanent glossary. Lessons link here. Plain words first — then the technical name.

ARR — Radarr / Sonarr ecosystem

Apps that automate your media library.

Radarr / Sonarr ecosystem

API — Application Programming Interface

How programs talk to each other.

Application Programming Interface

IP — Internet Protocol address

A device's network address.

Internet Protocol address

LAN — Local Area Network

Your home network.

Local Area Network

WAN — Wide Area Network

The internet side of your router.

Wide Area Network

DNS — Domain Name System

Turns names into IP addresses.

Domain Name System

DHCP — Dynamic Host Configuration Protocol

Automatically gives devices IP addresses.

Dynamic Host Configuration Protocol

VLAN — Virtual LAN

Separates devices into isolated networks.

Virtual LAN

VPN — Virtual Private Network

Encrypted / private network connection.

Virtual Private Network

UID — User ID

Linux number representing a user.

User ID

GID — Group ID

Linux number representing a user group.

Group ID

SMB — Server Message Block

Windows-style network file sharing.

Server Message Block

NFS — Network File System

Linux-oriented network file sharing.

Network File System

YAML — YAML Ain't Markup Language

Human-readable configuration format.

YAML Ain't Markup Language

Docker — Container platform

Runs apps in isolated packages.

Container platform

Container — Running Docker application

A lightweight packaged application.

Running Docker application

Image — Container template

Blueprint used to create a container.

Container template

Volume — Persistent storage

Data that survives container restarts.

Persistent storage

Bind mount — Host folder mounted into container

Lets Docker see one of your folders.

Host folder mounted into container

Port — Network communication endpoint

The door an application listens on.

Network communication endpoint

Reverse proxy — Gateway to internal websites

Gives internal services friendly / secure URLs.

Gateway to internal websites

Hardlink — Second directory entry for one file

Two names, one copy on disk — great for torrents.

Second directory entry for one file

Atomic move — Same-filesystem rename/move

Usenet finish step without a slow full copy.

Same-filesystem rename/move

Indexer — Torrent / Usenet search source

Where ARR apps look for releases.

Torrent / Usenet search source

Custom Format — ARR scoring rule

Grades releases so the best one wins.

ARR scoring rule

TRaSH — TRaSH Guides

Maintained playbook for ARR folder layouts and profiles.

TRaSH Guides

Recyclarr — TRaSH sync tool

Pushes guide profiles into Sonarr/Radarr automatically.

TRaSH sync tool

Prowlarr — Indexer manager

One place to manage search sources for ARR apps.

Indexer manager

Sonarr — TV automation

Finds, downloads, renames, and files TV shows.

TV automation

Radarr — Movie automation

Finds, downloads, renames, and files movies.

Movie automation

Lidarr — Music automation

ARR-style automation for music.

Music automation

Bazarr — Subtitle automation

Grabs subtitles for your library.

Subtitle automation

qBittorrent — Torrent client

Downloads torrent files.

Torrent client

SABnzbd — Usenet client

Downloads and unpacks Usenet posts.

Usenet client

Gluetun — VPN container

Puts only the torrent client behind a VPN.

VPN container

Seerr — Request UI family

Friends request movies/shows; ARR does the work.

Request UI family

Tautulli — Plex monitor

Shows who watched what on Plex.

Plex monitor

STT — Speech to Text

Voice → words.

Speech to Text

TTS — Text to Speech

Words → voice.

Text to Speech

LLM — Large Language Model

AI language model.

Large Language Model

Wyoming — Voice service protocol

Lets Home Assistant connect speech / wake-word services.

Voice service protocol

Piper — Text-to-speech engine

Gives Home Assistant a local voice.

Text-to-speech engine

Whisper — Speech recognition model

Converts spoken audio to text.

Speech recognition model

ESPHome — Device firmware / platform

Connects DIY devices directly to Home Assistant.

Device firmware / platform

HA — Home Assistant

Home automation platform.

Home Assistant

MQTT — Message Queuing Telemetry Transport

Lightweight messaging between smart devices.

Message Queuing Telemetry Transport

Zigbee — Low-power mesh radio

Sensors and plugs that hop messages through each other.

Low-power mesh radio

Thread — Low-power IPv6 mesh

Mesh used by many Matter devices (including some locks).

Low-power IPv6 mesh

Matter — Smart-home language

Shared way devices talk across brands.

Smart-home language

Border router — Thread ↔ LAN bridge

Device that lets Thread gadgets join your home network.

Thread ↔ LAN bridge

Root folder — Library path in ARR

Where Sonarr/Radarr file finished media (e.g. /data/media/tv).

Library path in ARR

Category — Download client label

Tag that sends torrents/nzbs into the right download folder (tv vs movies).

Download client label

PUID — Process user ID

Linux user number containers use when writing files.

Process user ID

PGID — Process group ID

Linux group number containers use when writing files.

Process group ID

FlareSolverr — Challenge proxy

Optional helper so indexers behind anti-bot pages can be tested.

Challenge proxy

Assist — HA voice pipeline

Home Assistant's built-in voice control system.

HA voice pipeline
