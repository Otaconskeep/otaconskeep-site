# Module 5 project — Guarded automation project

**Activity type:** Module project (integrated Apply/Create)  
**Module outcome:** Student can run n8n on the lab network only, build an RSS digest that explains JSON item cardinality, and require human approval before any mutating agent/SSH action.

## Task

Ship an RSS digest workflow plus one mutate path that cannot run without explicit human approval; document item counts at each node and secret handling.

## Evidence required

Workflow export (secrets stripped); approval screenshot/log; cardinality diagram; network exposure statement.
