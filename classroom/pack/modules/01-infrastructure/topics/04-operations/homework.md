# Homework — Container operations

**Module:** Module 1 — Infrastructure & Addressing  
**Activity type:** Homework / independent application  
**Bloom move:** push from guided practice into independent Apply/Analyze  
**Objective:** Given a running Compose service, the learner can inspect health and logs, perform a controlled image update, and roll back to a known-good state with evidence.

## Requirements

Complete **without** peeking at lab hints first. Then compare.

## Independent practice

**You do** — close the hints. Solve before opening the lab.

Write a one-page runbook for *one* service: health check, log command, update steps, rollback steps, and when not to update.

## Application task

1. Restate the learning objective as a checklist you can tick with evidence.
2. Produce the **build output** for this topic: operational runbook for one containerized service
3. Attach workbook evidence (commands, redacted screenshots, tables).
4. Write three spiral connections: how this topic uses an earlier skill, and where a later module will reuse it.

- [ ] Independent practice answers in workbook
- [ ] Evidence artifacts linked or pasted (secrets redacted)
- [ ] Spiral connections written
- [ ] Ready for topic quiz
