# Module 1 project — Infrastructure foundation project

**Activity type:** Module project (integrated Apply/Create)  
**Module outcome:** Student can virtualize a safe lab host, run persistent Compose services on isolated Docker networks, operate containers with update/rollback evidence, and read IPv4 address/mask/gateway to decide same-LAN vs via-gateway delivery.

## Task

Deliver one Linux guest (or Proxmox VM) running a two-service Compose stack on an isolated user-defined network, with a one-page ops runbook (health/logs/update/rollback) and an IP worksheet (address, mask, gateway, same-LAN vs gateway decision for two sample hosts).

## Evidence required

Screenshots/logs redacted; recreate-without-data-loss proof; DNS name call between services; IP math shown.
