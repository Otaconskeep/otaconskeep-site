# Prerequisite Assessment

Complete before Class 1. This is diagnostic, not a blocker — wrong answers route you to warm-up reading.

## Self-check (answer in the workbook)

1. Can you install an application on your computer and find its settings folder?
2. Do you know how to open a terminal (Linux/macOS) or PowerShell/CMD (Windows)?
3. What is a file path? Give one example from your OS.
4. What is Wi-Fi vs Ethernet in one sentence?
5. Have you ever restored a backup of anything? What made it trustworthy?
6. What does “port 80” mean to you today (even if fuzzy)?
7. Are you willing to use only authorized media sources in this course? (Yes required.)

## Scoring guide

| Score | Meaning | Action |
|---|---|---|
| 6–7 strong | Ready | Start Class 1 |
| 4–5 mixed | Ready with patience | Start Class 1; keep Class 15 early |
| 0–3 shaky | Need warm-up | Practice terminal basics + file paths for a day, then Class 1 |

## Warm-up tasks (if shaky)

- Create a folder, write a text file, copy it, delete the copy.
- Run `ipconfig` (Windows) or `ip addr` / `ifconfig` (Linux/macOS) and paste the output into your notes (redact if sharing).
- Explain to a friend what “backup” means without using the word “backup.”
