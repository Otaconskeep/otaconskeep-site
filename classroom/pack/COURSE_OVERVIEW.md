# Course Overview — Homelab Academy

**Site:** https://otaconskeep.github.io/classroom/  
**Source:** https://github.com/Otaconskeep/Classroom

## What this class teaches

You will design, build, operate, troubleshoot, and verify a private homelab:

- Virtualization and Docker operations
- ARR media automation (authorized content only)
- Home Assistant foundations and testable automations
- Secure remote access patterns
- Fully local voice (Whisper + Piper + Wyoming)
- Guarded n8n workflow automation
- IPv4 addressing literacy for real debugging

## Why it matters

Homelabs fail when people collect apps without a learning system. This Academy uses **Backward Design**, **Bloom’s Taxonomy**, **I do → We do → You do**, mandatory **Feynman teach-backs**, **retrieval practice**, **mastery gates**, and **spiral review** so skills stick and compound.

See `METHODOLOGY.md` for the full instructional design.

## Final capability (north star)

By the end, you can take a blank host and produce a working, documented system with evidence — not vibes — in the verification matrix.

## How every class works

Orient → Recall → Learn → Demonstrate → Practice → **Explain (Feynman)** → Apply → Assess → Reflect

You do not unlock the next class by clicking Next. You unlock it by completing the mastery gate.
