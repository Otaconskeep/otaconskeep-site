Workbook page 1 — What you're going to learn

Stop thinking in one-off docker run commands. Learn Compose so ARR is reproducible.

In plain words: Compose is a recipe card that starts many apps together.
More detail: Images are blueprints; containers are running copies; volumes/bind mounts keep data after delete.

Workbook page 4 — Guided notes (from the lecture ideas)

  • Lesson mantra: Containers are disposable. Data and configuration are not.
  • Lab progression: one container → convert to Compose → destroy/recreate → prove data survives.
  • After this class, Windows and Linux merge into the same Compose workflow.
In plain words: If you delete a container and your settings vanish, you stored data inside the disposable box. Put settings on a volume/bind mount.
More detail: Use Compose V2: docker compose (space), not only legacy docker-compose.
