Workbook page 1 — What you're going to learn

Understand physical host vs VM vs container, and why Home Assistant OS often lives in a VM while Sonarr usually lives in Docker.

In plain words: A big computer can pretend to be several smaller computers. A container is a lightweight packaged app. A VM is a whole fake PC.
More detail: Type-1 hypervisor sits on bare metal. VMs get full guest OS. LXC/containers share the host kernel. HA OS likes appliance VMs; ARR likes Compose containers.

Workbook page 4 — Guided notes (from the lecture ideas)

  • Host = the real machine. Guest = a VM running on it.
  • Bridge networking lets VMs look like devices on your LAN.
  • Windows students: learn the concept; practice with Hyper-V or skip to Docker on WSL2.
  • Linux/homelab students: optional spare-box Proxmox install — not required to finish Unit 1.
  • Exit question: Why HA OS as a VM, Sonarr as Docker?
In plain words: HA OS wants to feel like an appliance with add-ons. Sonarr is just an app — containers fit better.
More detail: Common pattern: Proxmox host → HA OS VM + Ubuntu VM for Docker ARR stack.
