The Default Roster

Five original agents, not a smaller copy of the private Keep

The Keep's own named agents are Metal Gear Solid / Overlord / Date A Live characters — fine for Antonio's private, personal install, not something a licensed public product can ship. Video Studio

Free, local, self-hosted — no paid API, ever

Everything Video Studio does runs on open-weight models on your own GPU through ComfyUI. No account, no subscription, no per-generation cost.

  • ✓ Images — Z-Image. Identity-preserving image-to-image generation, the same pipeline the Keep uses for agent pictures.
  • ✓ Video — LTX 2.3 / 2.5. Text-to-video and image-to-video, a two-pass draft-then-refine pipeline, plus start/end-frame interpolation.
  • ✓ Music. Local music generation in the same job queue and UI.
  • ✓ Actors, styles, scripts. A persistent library and a movie-project planner.
Real hardware floor: a GPU capable of running Z-Image and LTX locally. The installer's prerequisite check is expected to flag this explicitly rather than letting a user hit it mid-generation. ComfyUI setup will be automatic where possible, with a full manual fallback guide.

Install — One Command

The foundation layer is real. Install it today.

Not the finished product — there's no Dashboard, Codec, War Room, or Video Studio here yet. What's real: the versioned agent schema, the bounded relationship/mood formulas, the motion-manifest schema, and a schema-validated five-agent default roster, generated and written to disk. Requires Otacon Core already installed.

curl -fsSL https://raw.githubusercontent.com/Otaconskeep/otacons-ai-ecosystem/main/install_otacon_expansion.sh | bash

Fast-forwards the same repo Core already cloned, reuses Core's Python environment, runs the expansion/ test suite (50 tests) as a real acceptance gate, then generates and validates Aria/Vector/Ledger/Muse/Sentry — written to ~/.config/otacon/expansion/agents/. Rerunning it is safe. Reports FOUNDATION READY, DEGRADED, or FAILED, matching exit codes 0/2/1.

Engineering Contract

Agent creation is one transaction, not a row in a roster

Creating an agent — default or user-made — provisions roster registration, a stable ID, persona storage, hierarchy placement, greeting fast-path registration, voice binding, motion manifest, emotional-state initialization, relationship-graph seeding, dossier/journal initialization, room ownership, and Discord routing (if configured) as one logical unit. If it fails partway, the spec requires a clean rollback or an explicit, safely resumable provisioning state — never a Dashboard entry Codec can't actually use.

Identity and role are separate by design: an agent can be renamed without touching its hierarchy, authority, or room ownership. Motion manifests are validated against a strict schema specifically because a real bug — a manifest array silently comma-joined by JavaScript's fetch() — once broke an agent's motion while every other agent kept working. The canonical schema exists to make that class of bug structurally impossible.
