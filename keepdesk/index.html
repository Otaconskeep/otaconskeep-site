01 // Why it exists

Cloud teammates are cool. Owning the desk is cooler.

Grok Bot and OpenAI Operator / “Pilot”-class agents proved the vibe: persistent teammates that can use a computer while you walk away. They also proved the tax — your work, browsing, and files live on someone else’s machine, behind a subscription, with an agent loop you can’t fully inspect when it carts the wrong SKU.

Free to run

No required OpenAI or xAI API key. Pay for electricity and the GPU you already wanted.

Local brain

Ollama only. The stack refuses cloud LLM endpoints by design — prompts stay on your LAN.

Operator fun

Command Deck UI, LIVE browser pane, codec bar, Why dossiers. Mission control energy, not another chat box.

Keep Desk is built so soda research cannot silently become a coffee cart victory. When work is Incomplete or off-brief, the deck says so.

Like Grok Bot because…

Named teammates, computer use, skills/routines, background work, “bot” not autocomplete. Keep’s chrome is a Command Deck, not a Grok clone — same genre, different UI doctrine.

Goal-directed browser driving, approvals for risky steps, long jobs while you walk away. Session computer is yours (Chromium in Docker), not a vendor remote VM.

05 // Install

Docker Compose + Ollama

Linux host recommended. GPU optional but strongly recommended for a useful local model.

git clone https://github.com/Otaconskeep/keep-desk.git
cd keep-desk
cp .env.example .env
# Edit LOCAL_OLLAMA_URL / LOCAL_MODEL if needed
docker compose up -d --build
# Open http://127.0.0.1:5765/
  • Pull a model first: ollama pull gpt-oss:20b (or your preferred local chat model).
  • Default ports: 5765 Command Deck / API, 5766 browser service.
  • Point LOCAL_OLLAMA_URL at local Ollama only — cloud LLM bases are refused.

Full guide: INSTALL.md · FAQ: docs/FAQ.md.

06 // Honest limits

What Keep Desk is not

  • Not a frontier cloud model — 20B-class local plans thinner than Grok/GPT on nasty sites.
  • Not a full desktop GUI agent — browser-first; arbitrary native apps are out of claimable scope.
  • Not production-safe alone — bots are workers; gate money, deletes, and public posts (REX on OtaconsKeep).
  • Not zero-ops — you run Docker, Ollama, and disk backups.
  • Not a mobile app — use a browser / VPN if you need remote access.
  • CAPTCHA & anti-bot walls — same as every computer-use agent; sometimes you take over.

07 // FAQ

Quick answers

Is it free?

Software yes. You pay for power and hardware. No required cloud LLM subscription for the core loop.

Does it phone home to OpenAI or xAI?

No. Local Ollama only; cloud LLM endpoints are refused.

What does 91.6% mean?

Weighted claimable score on our requirements matrix with critical gate PASS — not “91.6% of Grok’s product.” Day-to-day feel is closer to ~75% once you count model quality, mobile, and connectors.

Can it buy things with my card?

Treat purchases as dangerous. Research is in scope; production spending needs human approval and external gates.

Hollow / off-brief?

Honesty modes: Incomplete work must not fake victory; mismatched recommendations (wrong product family) are refused.
