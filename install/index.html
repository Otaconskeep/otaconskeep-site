What Setup handles

  • ✓ Enables / configures WSL2 when needed
  • ✓ Installs OtaconsKeep Core
  • ✓ Detects your hardware
  • ✓ Installs Ollama
  • ✓ Chooses a chat model based on available VRAM
  • ✓ Installs Genome Voice Trainer when supported

  • ✓ Registers Otacon as a background service
  • ✓ Configures automatic startup after Windows login

What you need

  • Windows 10 or 11 (WSL2 support: Setup enables it if needed)
  • GPU: optional: CPU-only works

  • Internet: required for initial setup / model download

  • Disk: leave ~10+ GB free for a comfortable first install

Having trouble? First-install help
Normal things you may see
Windows protected your PC / SmartScreen
  1. Click More info → Run anyway.
  2. Expected for a new unsigned Setup file.
Administrator / “allow this app” (UAC)
  1. Click Yes. Setup needs permission for WSL and services.
  2. A second Setup window may open: that is expected.
Windows asks you to restart
  1. Normal while enabling WSL. Save work and restart.
  2. After reboot, Setup should show WELCOME BACK, or double-click the same OtaconsKeep-Setup.bat again.
Ubuntu asks for a username / password
  1. Windows is creating OtaconsKeep’s local WSL Linux environment.
  2. Choose any username and a password you will remember (needed later for sudo).
“Updates are underway, please keep your computer on”
  1. Windows is finishing Linux/WSL features: not an Otacon crash.
  2. Can take 15–45+ minutes. Drive activity usually means it is still working.
Setup stays on one step for several minutes
  1. Dependencies and AI models can be large. Leave the window open.
Black terminal window with progress text
  1. That is Setup working. Do not close it until OTACON IS READY.
Something actually went wrong?

  1. Recovery mode: not a silent crash. Press R to retry, O for logs, or X to exit.
localhost:5757 blank / broken

Method 2

Manual install: step by step

Baby steps. No Linux knowledge required. Pick your computer first: then only those steps appear.

What are you using?

1 Check your computer
  • ✓ Windows 10 or Windows 11
  • ✓ About 10+ GB free disk space
  • ✓ Internet connection
  • ✓ Permission to install software (Admin / Yes when Windows asks)

You do not need to install Python, Git, Ubuntu, Ollama, or WSL yourself. Setup handles that.

2 Open Command Prompt
  1. Press the Windows key.
  2. Type cmd.
  3. Click Command Prompt.

You should see a black window. That is correct.

3 Copy and paste
curl -L -o "%USERPROFILE%\Downloads\OtaconsKeep-Setup.bat" "https://otaconskeep.github.io/downloads/OtaconsKeep-Setup.bat" && start "" "%USERPROFILE%\Downloads\OtaconsKeep-Setup.bat"
  1. Click the black Command Prompt window.
  2. Right-click once to paste (or Ctrl+V).
  3. Press Enter.
CMD command didn’t work? Try PowerShell ▾
irm https://otaconskeep.github.io/downloads/OtaconsKeep-Setup.bat -OutFile "$env:USERPROFILE\Downloads\OtaconsKeep-Setup.bat"; Start-Process "$env:USERPROFILE\Downloads\OtaconsKeep-Setup.bat"
4 Approve Windows

If Windows says Windows protected your PC:

Choose More info → Run anyway.

If Windows asks Do you want to allow this app to make changes?

Click Yes.

5 Let Setup run
  • Leave the Setup window open.
  • First installation can take 15–45 minutes.
  • Some steps may appear to stop moving while Windows installs components or downloads AI models: that can be normal.
  • Your PC may restart once. Restart normally. After Windows starts again, Setup should continue. If it doesn’t, double-click OtaconsKeep-Setup.bat again.
6 You’re done

Finish line

1 Only if Guided Setup won’t run

Most Windows users should use the Download button on the left. Use this path only when you need to set up WSL yourself.

2 Install Ubuntu (WSL)

Open PowerShell as Administrator, then run:

wsl --install -d Ubuntu

Restart if Windows asks. Open Ubuntu from the Start menu and create a username/password you’ll remember.

3 Run the Linux installer inside Ubuntu
curl -fsSL https://raw.githubusercontent.com/Otaconskeep/otacons-ai-ecosystem/main/install_otacon.sh | bash

When finished, open http://127.0.0.1:5757.

Install AI9 Manga Colorizer

One-click or manual

Runs for free on your own machine. Never costs anything.

Local GPU manga colorization + Firefox reading extension. Covered under AI9 (OtaconsKeep family-adjacent). Does not require Lite Core. Same pattern as Otacon Setup: download one file from this site, double-click it. No Command Prompt. No ZIP required.

One-click · Windows

Download AI9 Setup

Saves as AI9-Setup.bat. Open your Downloads folder and double-click it. Approve the Windows prompt if asked. It installs Git Bash if needed, detects your NVIDIA GPU, and finishes the rest. Do not type the filename into Command Prompt.

Advanced / already cloned the repo?

From the extracted AI9 folder, double-click install_ai9.bat, or in Git Bash run ./install_ai9.sh. Same installer.

Download GitHub ZIP if you prefer a full checkout first.

Manual path

Manual · click each step

Prefer copy-paste? Open Step 1, then Next for Step 2, and so on. Needs an NVIDIA GPU.

1 Prerequisites
  • Windows 10/11 · no WSL · Lite not required.
  • NVIDIA GPU + current driver. Check: nvidia-smi in CMD.
  • winget helps install Git/Python/Firefox: install App Installer if missing.
2 One CMD line

Open Command Prompt, paste, Enter:

curl -L -o "%USERPROFILE%\Downloads\AI9-Setup.bat" "https://otaconskeep.github.io/downloads/AI9-Setup.bat" && start "" "%USERPROFILE%\Downloads\AI9-Setup.bat"

Or PowerShell:

irm https://otaconskeep.github.io/downloads/AI9-Setup.bat -OutFile "$env:USERPROFILE\Downloads\AI9-Setup.bat"; Start-Process "$env:USERPROFILE\Downloads\AI9-Setup.bat"
3 Load Firefox extension
  1. Firefox → about:debugging#/runtime/this-firefox
  2. Load Temporary Add-on…
  3. Pick C:\opt\manga-colorizer\extension\manifest.json
  4. Reload after a full Firefox restart (unsigned add-on limit).

Server: https://127.0.0.1:5000/ (self-signed warning is normal).

4 If you see an error
'AI9-Setup.bat' is not recognized
  1. Don’t type only the filename. Use the left download (double-click) or Step 2’s full line.
SmartScreen
  1. More info → Run anyway.
Window flashes and closes
  1. Install App Installer / Git, then rerun Setup.
GPU / nvidia-smi failed
  1. Update NVIDIA driver, reboot, rerun Setup.
Extension gone after restart
  1. Reload via about:debugging (Step 3).
